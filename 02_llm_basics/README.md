# 第二章 大语言模型基础

掌握提示词工程，需要先理解其作用对象，即大语言模型（Large Language Models, LLMs）的基本工作原理。正如驾驶员了解汽车的基本机械原理才能更好地操控车辆，提示词工程师也需要理解语言模型的运作机制，才能设计出更有效的提示词。

本章从技术角度介绍大语言模型的核心概念，包括它们如何理解和生成文本、当前主流模型的特点与差异、关键参数对输出的影响，以及上下文窗口。这些知识有助于读者理解提示词为何有效，以及如何根据模型特性调整提示策略。

本章不深入机器学习的数学原理，只提供足够的背景知识，使读者能够更有针对性地设计提示词。
