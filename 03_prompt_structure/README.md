# 第三章 提示词的基本结构

提示词设计的核心是构建结构良好、表达清晰的提示词。如同写作需要遵循一定的结构和规范，提示词设计也有其内在逻辑和组成要素。

有效的提示词是经过组织的信息集合。它需要清晰地传达任务目标、提供必要的上下文、说明期望的输出格式，并在需要时给出示例或约束条件。这些结构元素相互配合，共同引导模型产出高质量的结果。

本章介绍提示词的核心组成要素及各要素的作用和设计原则，并通过示例说明如何将这些要素整合在一起。
